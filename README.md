# MQTT Handheld Hardware Monitor releases

No installation package is available yet. R36 ARM64 and TrimUI ARM64 packages must both be built and verified before a release is published. Do not use the old source-based installation instructions: the source repository is private.

When a release is ready, installation and update instructions will be published here with the packages and checksums. There is currently no public installation command.
